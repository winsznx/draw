# Hackathon delta

This hackathon process record is DRAW's eligibility note. DRAW was built from scratch during HackCanton Season 3, so there's no earlier version to compare against. The product is in [PRODUCT.md](PRODUCT.md) and the proof in [PROOF.md](PROOF.md).

- First commit: 2026-10-01 (`36069bc`). The build period is 2026-09-18 to 2026-10-09.
- No earlier code, template or repository was reused. The Daml model, scripts, app and documents were all written during the event.
- Third-party material used as published: Splice 0.8.4 Token Standard DARs (pinned with hashes in [SPONSOR_FINDINGS.md](SPONSOR_FINDINGS.md)), the Splice LocalNet bundle, the Daml SDK, React, Next.js, OpenNext for Cloudflare, TanStack Query, Playwright, and Vite for the earlier web app.
- Single author.
- DRAW was built with AI-assisted tools (Claude Code) for code, tests and documentation. The author directed the work and is responsible for all of it. The rules the AI coding assistant worked under are in [CLAUDE.md](../CLAUDE.md), public as part of this disclosure. The product itself has no AI features.
- Every result file, receipt and log under [evidence/](../evidence) was written during the event by scripts in this repository. The 14 NOTE.md files next to failed, aborted or skipped runs were written by hand at the time to record each cause.
